# 🔑 FinTag - Tap Smart, Track Smart 💳

**FinTag** adalah platform pelacakan keuangan modern berbasis fisik-ke-digital yang dirancang khusus untuk mahasiswa dan generasi muda. Menggabungkan kegunaan fungsional gantungan kunci NFC (Near Field Communication) berkualitas tinggi dengan ekosistem pelacakan keuangan digital yang cerdas, efisien, dan menyenangkan.

Sistem ini didesain penuh sebagai aplikasi full-stack terintegrasi yang tidak hanya membantu mencatat pemasukan dan pengeluaran secara sekejap, tetapi juga menghadirkan asisten finansial cerdas ditenagai oleh **Google Gemini AI**, gamifikasi produktivitas, serta toko kustomisasi gantungan kunci premium langsung ke tangan pengguna.

---

## 🎯 Tujuan Utama (Purpose)

1. **Mendigitalkan Pencatatan Keuangan Instan**: Menjembatani kesenjangan pencatatan manual yang melelahkan dengan cara mendekatkan interaksi fisik (gantungan kunci NFC) ke smartphone pengguna guna meningkatkan kedisiplinan finansial.
2. **Edukasi Finansial Kreatif**: Memberikan pemahaman literasi keuangan kepada kelompok muda/mahasiswa melalui pendekatan gamifikasi, kuis interaktif, dan tantangan menabung harian.
3. **Meningkatkan Produktivitas Pengguna**: Mengintegrasikan alat manajemen waktu (Teknik Pomodoro) serta hiburan yang sehat (pemutar musik dan mini-games) ke dalam satu wadah produktivitas terpusat.
4. **Kemandirian Finansial Mahasiswa**: Menyediakan data analitis transaksi yang transparan agar mahasiswa dapat dengan mudah membatasi perilaku boros dan mencapai kestabilan finansial harian.

---

## 🚀 Manfaat Terbaik FinTag (Benefits)

* **Praktis & Instan**: Cukup dekatkan gantungan kunci NFC FinTag ke ponsel, halaman pencatatan keuangan langsung siap mendeteksi transaksi secara real-time.
* **Literasi Keuangan Sejak Dini**: Tantangan harian (seperti *No Jajan Hari Ini*) mendorong kebiasaan menghemat secara sukarela dan menyenangkan.
* **Gaya Hidup Estetik**: Kustomisasi tak terbatas (menyediakan 10 pilihan template modern dan variasi foto formal) memungkinkan gantungan kunci NFC berfungsi sebagai aksesoris bergaya yang merepresentasikan personalitas pengguna sendiri.
* **Selalu Terkendali**: Panel Admin yang andal menjamin pesanan gantungan kunci diproses secara instan melalui integrasi pengiriman chat pesanan ke WA otomatis, dan mempermudah sinkronisasi data dari admin ke semua pelanggan.
* **Bimbingan FinBot AI**: Bertanya apa saja tentang tips berhemat, ide bisnis sampingan, atau cara menabung yang efektif secara langsung via obrolan cerdas 24/7.

## 💎 Fitur Unggulan FinTag

Aplikasi FinTag mengemas berbagai fitur interaktif kelas dunia yang disusun dalam visual modern, elegan, dan estetik bawaan *Space Grotesk* ditenagai efek animasi mulus dari *motion*:

### 1. 📊 Financial Tracker (Pelacak Keuangan Cerdas)
* **Pencatatan Instan**: Form pencatatan pemasukan dan pengeluaran yang rapi, lengkap dengan kategori (Makanan, Edukasi, Transportasi, Hiburan, dll), jumlah nominal, dan deskripsi.
* **Visualisasi Chart Komprehensif**: Menggunakan grafik dinamis dari kartu laporan pengeluaran terperinci agar riwayat keuangan dan tren pengeluaran mudah dibaca dalam sekejap.
* **Limit Budgeting**: Setel budget bulanan Anda, dan biarkan indikator progress bar memberikan peringatan visual jika dompet Anda mendekati batas pengeluaran maksimum.

### 2. 🛍️ FinTag Store & Live Mockup (Toko Kustomisasi Akrilik)
* **Katalog Produk Standar**: Pesan gantungan kunci fisik original FinTag (FinTag Standard) atau kartu NFC premium (FinTag Card Pro).
* **Fitur Custom Desain Komplit**:
  - **Pas Foto Formal**: Kustomisasi latar belakang merah/biru solid formal untuk pas foto akademik/kartu tanda mahasiswa.
  - **10 Pilihan Template Estetik**: Termasuk frame *Spotify Music Player*, retro *Polaroid*, *Anniversary Calendar*, gaya neon *Cyberpunk*, ganci gaya tiket konser rindu, maskot hewan lucu *Chibi*, panel strip *Manga*, duplikasi feed *Instagram*, peta rasi bintang *Cosmic Zodiac*, atau ornamen retro *Neo-Memphis Geometric*.
* **Bentuk Akrilik Pilihan**: Atur bentuk gantungan kunci fisik yang dipesan langsung secara visual, mencakup bentuk **Persegi (Square)**, **Persegi Panjang (Rectangle)**, dan **Oktagonal (Premium Hexagonal)**.
* **Live Interactive 3D Mockup**: Mengubah dimensi bingkai mockup dengan *soft reflection* dan efek berkilau secara real-time sesuai aspek rasio gambar serta bentuk akrilik yang dipilih.
* **WhatsApp Order Gateway**: Sistem formulir pesanan instan otomatis menyalin format rincian fisik, nominal pembayaran, data penerima, hingga jenis pesanan langsung ke ruang obrolan Admin WhatsApp.

### 3. 🤖 FinBot AI Chat (Asisten Keuangan Pintar)
* Ditenagai oleh **Google Gemini AI** server-side secara aman (no-client API leak).
* Memahami konteks finansial lokal, memberikan saran cerdas menghemat, rencana budgeting harian, inspirasi bisnis sampingan untuk mahasiswa, hingga panduan lengkap navigasi seluruh halaman FinTag.

### 4. 🎮 Mini Games Zone (Gamifikasi Berhadiah)
* Menyediakan **5 pilihan game interaktif** untuk meredakan stres sekaligus menguji kecerdasan:
  - **Hemat atau Boros**: Kuis keputusan finansial yang edukatif dan lucu.
  - **Coin Catch**: Tangkap koin emas yang jatuh untuk melatih kecepatan respons motorik.
  - **Memory Match**: Game asah otak menemukan pasangan logo kartu finansial.
  - **Quick Tap**: Tantangan kecepatan menepuk tombol gasing sebelum waktu habis.
  - **Color Reflex**: Melatih konsentrasi visual lewat penyesuaian refleks teks warna yang cepat.

### 5. 🎯 Daily Challenge (Tantangan Pembiasaan Baik)
* Bangun kebiasaan finansial sehat melalui daftar tantangan harian dinamis (seperti *No Jajan Hari Ini*, *Minum Air 2L*, dan *Jalan Kaki 5000 Langkah*).
* Selesaikan tantangan dan kumpulkan poin kepatuhan guna memotivasi gaya hidup sehat dan hemat setiap pagi.

### 6. 🍅 Pomodoro Productivity Timer
* Manfaatkan teknik Pomodoro terintegrasi untuk membantu Anda fokus belajar selama 25 menit diselingi dengan istirahat 5 menit secara otomatis.
* Dilengkapi visual animasi sirkular yang elegan serta efek notifikasi suara lembut untuk menandai sesi belajar berakhir.

### 7. 🎵 Interactive Music Player
* Hidupkan produktivitas Anda sembari mendengarkan lagu instrumen santai pengisi fokus kerja.
* Dilengkapi navigasi trek audio, slider pengatur baris progress lagu, dan visualisator bar musik dinamis. Playlist lagu terkelola secara dinamis dan sinkron di Cloud database.

### 8. 🕶️ AR Guide & NFC Tutorial (Panduan Penempatan Tag)
* Halaman edukatif mengenai cara mengaktifkan chip NFC di ponsel cerdas (Android & iOS).
* Panduan simulasi penempatan saku kustom serta visualisasi letak koordinat chip pemancar pada casing ganci akrilik.

### 9. 💬 Hubungi Dev (Feedback System)
* Ruang terbuka bagi seluruh pelanggan untuk menyampaikan apresiasi (**Kesan**), aspirasi (**Saran**), serta laporan gangguan (**Bug**) yang dikustomisasi dengan preset praktis.
* Dirancang anti-refresh instan saat pengiriman pesan lokal, memberikan konfirmasi sukses yang nyaman sebelum data tersimpan dengan aman ke Firebase database.

### 10. 🏛️ Admin Dashboard (Panel Kontrol Pusat)
* Ruang kendali eksklusif yang dilindungi kredensial admin secara real-time.
* Kelola pesanan masuk (*Orders*), monitor kiriman masukan dari pelanggan (*Feedback*), kelola katalog produk toko, serta update playlist trek audio musik untuk didengarkan seluruh pengguna.

## 🛠️ Arsitektur & Teknologi (Tech Stack)

Aplikasi FinTag dibangun dengan standar performa dan penulisan tipe modern tingkat tinggi:

* **Frontend**:
  - **React 18** dengan **Vite** (bundler super cepat).
  - **TypeScript** untuk jaminan modularitas tipe data yang aman dan andal.
  - **Tailwind CSS** untuk gaya tampilan responsif, modern, dan berkepribadian tinggi.
  - **Motion (Framer Motion)** untuk menggerakkan transisi halaman, *bounce preview* ganci, geseran sidebar, dan mikro-interaksi tombol.
  - **Lucide React** sebagai pustaka ikon vektor seragam dan tajam.
  - **Canvas Confetti** untuk perayaan visual animasi yang meriah saat pesanan ganci berhasil dikonfirmasi.

* **Backend & API**:
  - **Node.js** dengan framework **Express** server-side.
  - **Google Gen AI (Gemini SDK)** yang berjalan di server guna mengamankan API key dari inspeksi browser pelanggan.
  - **Weather API Integration**: Menyediakan status widget cuaca lokal di halaman aplikasi yang terupdate secara periodik.

* **Database & Cloud Storage**:
  - **Firebase Firestore**: Digunakan untuk sinkronisasi pesanan (*orders*), masukan pengguna (*feedbacks*), database produk, serta playlist musik secara real-time.
  - **Firebase Authentication**: Untuk mengamankan akun pengguna dan admin dengan aman.

## 🚀 Cara Menjalankan Aplikasi di Lokal

Guna menikmati lingkungan pengembangan terbaik dengan fitur sinkronisasi real-time, ikuti langkah-langkah instalasi berikut:

### 1. Prasyarat Sistem
* Pastikan Anda telah memiliki **Node.js (versi 18+)** terinstal di perangkat komputer Anda.

### 2. Instalasi Dependensi
Jalankan perintah berikut di root folder untuk menginstal semua modul paket yang tertera di `package.json`:
```bash
npm install
```

### 3. Konfigurasi Environment Variables (`.env`)
Buat file bernama `.env` di direktori utama (sejajar dengan `.env.example`), lalu isi kunci akses berikut secara lengkap (jangan cantumkan kuncinya ke dalam `.env.example` demi keamanan privat):
```env
# Google Gemini API Key untuk AI Assistant FinBot
GEMINI_API_KEY=your_gemini_api_key_here

# Firebase Credentials konfigurasi Web App Anda
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### 4. Menjalankan Server Pengembangan (Dev Mode)
Jalankan perintah dev berikut untuk mengaktifkan Express server beserta integrasi Vite middleware secara sinkron pada port **3000**:
```bash
npm run dev
```
Setelah berjalan, buka penjelajah web Anda dan ketikkan alamat: `http://localhost:3000`

### 5. Kompilasi Produksi (Production Build)
Untuk membuild seluruh program menjadi file produksi statis yang teroptimasi di dalam folder `/dist`:
```bash
npm run build
```
Untuk menguji coba file hasil build dalam mode replika produksi:
```bash
npm run start
```
